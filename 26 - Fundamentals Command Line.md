**`dir`**                     displays a list of all files and subfolders inside your current directory.
**`dir ..`**               back step.
**`cls`**                        erase all.
**`cd`**                        change directory.
**`mkdir or md`**            Creates a directory or subdirectory
**`md "D:\namefolder"`.**
**`rmdir`**            remove directory.
**`color a`**                        change color.
**`title nametitle`**                 change title cmd.
**`systeminfo `**        which displays detailed configuration information about a computer and its                                             operating system    **`systeminfo > namefile.txt`.**
**`echo helloworld`**                            **command** is a built-in tool used to print text to the screen.
**`call file.txt`**                   open any file
**`type file.txt`**               show content in files 
**`ren file1.txt file.html`**             used to change the name of one or more files or directories
**`copy file.html D:\`**               used to **duplicate one or more files** from one location to another 
`move file2.txt D:\`               relocating files and directories from one path to another
`ipconfig`                       displays your computer's current network connection settings
`ipconfig \all`               
`ipconfig \flushdns`
